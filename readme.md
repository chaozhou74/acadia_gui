# acadia_gui
a gui interface for browsing experiment data generated by acadia (will expand to a generic data browser in the future)


## Principles
- The `process_current_data/update` functions gets the data ready for the plot
- plots are remade everytime in live plot, so the plotting functions can be written in very *straightforward* ways. 
  no need to do plot.update_data, separating the plot in init, update, finalize, etc.
- The old plot is cleared every time. so there shouldn't be leakage or duplicated plots.
- Even if there is any leakage or gui just somehow crushes, since the plotting is a separate
    process, it won't hurt the running runtime, and data will still be saved.
    can even restart the gui when it breaks, and plot update will continue from there
